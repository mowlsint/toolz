# White Lightning Tests

`node white-lightning/tests/test.cjs` prüft die Datumserkennung, Platzhalter, Trennung von Ereignis- und Meldedatum und Deduplizierung ohne externe Dateien.

Mit `WL_MSG_FIXTURE_DIR` können **nur auf dem eigenen Rechner** zusätzliche Outlook-MSG-Dateien getestet werden. Keine privaten Originale, Testmails oder PDF-Anhänge im öffentlichen Repository ablegen.
